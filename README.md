# ปริศนาศัพท์ดนตรี

อ่านคำใบ้ภาษาไทยแล้วเติมศัพท์ดนตรีด้วยตัวอักษรอังกฤษ เปิด `index.html` ด้วย Chrome หรือ Edge ได้โดยตรงโดยไม่ต้องติดตั้งหรือเชื่อมต่ออินเทอร์เน็ต เลือกคำใบ้หรือช่องในตาราง พิมพ์คำตอบ แล้วกด **ตรวจคำตอบ**

บนคีย์บอร์ดคอมพิวเตอร์ ใช้ Tab หรือ Shift+Tab เปลี่ยนคำ ลูกศรเปลี่ยนช่อง Space สลับแนวนอนและแนวตั้งที่จุดไขว้ และ Esc ไปยังปุ่มตรวจคำตอบ บนโทรศัพท์ใช้แป้นที่อยู่ในหน้าเว็บได้

## แก้ไขด้วย AI

ค้นหาโซนใน `index.html`:

- โซน A: ชุดคำศัพท์และคำใบ้ เพิ่มชุดใหม่ได้ที่นี่
- โซน B: ค่าตั้งต้น เช่น ขนาดตารางและจำนวนครั้งที่ลองสร้างตาราง
- โซน C: แกนเกม ไม่ควรแก้
- โซน D: หน้าจอและการบันทึก ไม่ควรแก้ถ้าไม่จำเป็น
- โซน E: ที่เขียนส่วนเสริม ใช้เหตุการณ์และเครื่องมือของ `Game`

ตัวเลือกส่วนเสริมสำหรับการสอบ เลือกทำหนึ่งข้อ:

1. **ปุ่มใบ้** — reveal one letter of the selected word and count the hints used.
2. **จับเวลา** — a timer from the first letter to the finish, with the best time per set saved.
3. **ชุดคำศัพท์ของฉัน** — a new set of at least 8 words with Thai clues, added in zone A.
4. **เสียงตอบรับ** — a short sound when a word is solved and when the puzzle is finished.
5. **แถบความคืบหน้า** — a drawn progress bar of solved words in `slotHud`.

หลังแก้ไขให้เปิด **ตั้งค่า → ตรวจระบบ** และทดลองเล่นจริงด้วย คำที่สร้างตารางไม่ได้และรายการข้อมูลที่ถูกปฏิเสธจะแสดงในแผงนี้ ผลผ่านตรวจแกนเกมเท่านั้น ไม่ได้รับประกันว่าส่วนเสริมหรือหน้าตาถูกต้องทุกกรณี

## เผยแพร่

1. Fork หรือสร้าง GitHub repository ของตนโดยให้ `index.html` และไฟล์อื่นในโฟลเดอร์นี้อยู่ที่รากของ repository
2. ใน repository เปิด **Settings → Pages** เลือก **Deploy from a branch** เลือก branch ที่มีไฟล์และโฟลเดอร์ `/ (root)` แล้วบันทึก
3. รอ GitHub สร้างเว็บไซต์ จากนั้นเปิดลิงก์ที่หน้า Pages และลองเล่นอีกครั้ง นอกจากนี้ยังนำโฟลเดอร์เดียวกันไปอัปโหลดขึ้น Netlify หรือ Vercel แบบ static site ได้
